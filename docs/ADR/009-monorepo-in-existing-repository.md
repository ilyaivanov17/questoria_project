# ADR-009: единый monorepo в questoria_project

- **Статус:** принято
- **Дата:** 2026-11-16
- **Контекст:** исходный README предлагал вынести production-код в отдельный репозиторий. Владелец проекта подтвердил, что новый репозиторий `questoria_project` предназначен для дальнейшей разработки и исходный код должен размещаться здесь.
- **Решение:** хранить в одном Git-репозитории PRD, MVP Execution Specification, master blueprint, автономный UI-прототип, frontend, backend, общие контракты, Prisma schema, инфраструктуру и ADR. Использовать pnpm workspaces.
- **Следствия:** документация и прототип остаются на месте; приложение развивается в `apps/web` и `apps/api`. CI и команды запуска обслуживают весь monorepo. Не создавать второй репозиторий без нового ADR.
- **Альтернативы:** отдельные репозитории для документации, frontend и backend — отклонены на текущем этапе из-за лишней координации и необходимости синхронизировать API-контракты.
