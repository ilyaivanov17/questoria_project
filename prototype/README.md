# Questoria — интерактивный UI-прототип

Это автономный браузерный прототип интерфейса образовательной квест-платформы.

## Как открыть

1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Перейдите в «Квесты» или нажмите «Попробовать демо-квест».
4. Пройдите три демонстрационных задания.

Для локального просмотра достаточно открыть файл напрямую; сервер и установка пакетов не требуются.

## Что уже работает

- Главная и каталог с тремя тематическими направлениями.
- Карточки шести запланированных квестов; полностью интерактивно доступен один демо-квест.
- Демо-квест с тремя типами заданий: выбор ответа, упорядочивание шагов, ввод ответа.
- Подсказки, обратная связь и объяснения.
- Прогресс и история результатов.
- Демонстрационные XP и монеты, начисляемые один раз за первое прохождение.
- Простейший магазин косметических наград.
- Локальное сохранение завершённого демо-прогресса, баланса и покупок в `localStorage`.
- Адаптивная вёрстка для смартфона и десктопа.

## Важно

Это только UI/UX-прототип. Все данные, ответы и начисления находятся в браузере, поэтому их легко изменить через DevTools. Сохранение выполняется только в этом браузере и не синхронизируется между устройствами. Нельзя использовать прототип для реальных пользователей, детских аккаунтов, оплаты или хранения чувствительных данных. В production ответы и экономика должны быть на сервере, как указано в PRD и MVP Execution Specification.
